# داشبورد بازارهای مالی ایران

داشبورد فارسی و راست‌چین مبتنی بر Streamlit برای مشاهدهٔ شاخص و فیلتر نمادهای بورس تهران، بازار طلا و نرخ تتر.

## امکانات

- فیلتر امتیازدهی سهام و ETF و نمایش سیگنال‌های حاصل از شروط کمی
- برآورد فشار عرضه و تقاضا با شمارش عددی نمادها
- برآورد جریان خالص حقیقی و نمادهای دارای بیشترین ورود و خروج
- دریافت قیمت انس و طلای ۱۸ عیار از ره‌آورد و محاسبهٔ ارزش جهانی و اختلاف قیمت داخلی
- دریافت نرخ USDT/IRT از API عمومی صرافی تبدیل
- کش داده با TTL شصت ثانیه و مدیریت خطای منابع شبکه

## اجرا

Python 3.10 یا جدیدتر پیشنهاد می‌شود.

```bash
python -m venv .venv
```

فعال‌سازی محیط مجازی:

```bash
# Windows PowerShell
.venv\Scripts\Activate.ps1

# Linux/macOS
source .venv/bin/activate
```

نصب وابستگی‌ها و اجرای برنامه:

```bash
pip install -r requirements.txt
streamlit run app.py
```

به‌صورت پیش‌فرض برنامه روی `http://localhost:8501` در دسترس است. برای دسترسی در شبکهٔ داخلی، آدرس bind متناسب با تنظیمات شبکهٔ سرور را به Streamlit بدهید.

## منابع داده و محدودیت‌ها

- دادهٔ بورس از API عمومی TSETMC دریافت می‌شود؛ دسترسی سرور به دامنه‌های TSETMC لازم است.
- قیمت دلار/تتر از بازار USDT/IRT صرافی تبدیل دریافت می‌شود و در صورت دسترس نبودن، منبع جایگزین با نام خودش گزارش می‌شود.
- قیمت انس و طلای داخلی از API عمومی ره‌آورد دریافت می‌شود.
- API عمومی تبدیل در مسیر استفاده‌شده آمار تجمیعی سقف، کف و حجم ۲۴ ساعته ارائه نمی‌کند؛ این مقادیر به‌صورت حدسی نمایش داده نمی‌شوند.
- «سیگنال خرید» و پیش‌بینی جهت بازار خروجی فیلترهای کمی‌اند و تضمین بازده یا توصیهٔ سرمایه‌گذاری نیستند.
- مقایسهٔ جریان خالص با جلسهٔ قبل به وجود سابقهٔ ذخیره‌شده در فایل محلی `market_flow.sqlite3` نیاز دارد. این فایل برای انتشار در Git نادیده گرفته شده است.
- برای Vercel، پروژه از `Dockerfile.vercel` و Container runtime آزمایشی Vercel استفاده می‌کند. فایل SQLite داخل کانتینر ماندگار نیست؛ تاریخچهٔ مقایسه پس از خاموش/جایگزینی نمونه باقی نمی‌ماند.
